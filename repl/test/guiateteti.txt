Guía: tateti paso a paso

Arrancá con ./r3lin repl/repl.r3. Después de cada prueba, /reset para limpiar la pila. Los comentarios | ... van al final de la línea. Tablero: 0 vacío, 1 X, 2 O.

1. La pila

2 3 +
dup *

Pila: [25].

2. Datos: el tablero (9 celdas)

#board 0 0 0 0 0 0 0 0 0

3. Acceso a una celda

:cell 3 << 'board + ; | n -- dir
:put cell ! ; | v n --
:get cell @ ; | n -- v
1 4 put 4 get

Pila: [1]. Poné y leé en la misma línea (hueco 1).

4. Dibujar una casilla

:.c 
	0? ( drop "." .write ; ) 
	1 =? ( drop "X" .write ; ) drop 
	"O" .write ;
	
0 .c 1 .c 2 .c .flush

Salida: .XO. Sin .flush no se ve nada.

5. Dibujar el tablero

:.row 
	3 * dup 3 + swap 
	( over <? 
		dup get .c " " .write 
		1+ ) 2drop .cr ;
		
:.board 
	0 ( 3 <? dup .row 1+ ) drop 
	.flush ;
	
1 4 put 2 0 put .board

Salida:

O . .
. X .
. . .

6. ¿Hay tres iguales?

:same3 
	get rot get rot get rot 
	pick2 =? ( 
		over =? ( drop nip ; ) 
		) 
	3drop 0 ; | a b c -- v
	
:win 
	0 1 2 same3 1? ( ; ) drop 
	3 4 5 same3 1? ( ; ) drop 
	6 7 8 same3 1? ( ; ) drop 
	0 3 6 same3 1? ( ; ) drop 
	1 4 7 same3 1? ( ; ) drop 
	2 5 8 same3 1? ( ; ) drop 
	0 4 8 same3 1? ( ; ) drop 
	2 4 6 same3 ; | -- 0/1/2
	
1 0 put 1 4 put 1 8 put win

Pila: [1]. Con 2 0 put 1 4 put win da [0].

7. Jugar (rechaza casillas ocupadas)

:play 
	dup 
	get 1? ( 3drop 0 ; ) drop 
	put 1 ; | jugador celda -- ok
	
1 4 play 2 4 play

Pila: [1 0]. No uses move como nombre.

8. Computadora: primera casilla libre

:ai 
	0 ( 9 <? 
		dup get 0? ( drop ; ) drop 
		1+ ) 
	drop -1 ; | -- celda/-1
	
1 0 play drop 1 1 play drop ai

Pila: [1 1 2], la última es la celda 2.

9. Depurar

1 2 3 .rs imprime la pila sin consumirla; ponelo dentro de cualquier palabra.
/src muestra el programa generado y /term la salida de la última corrida.

10. El juego completo (lazo con teclas)
Esto sale del REPL: /edit abre r3ide con el proyecto. Ahí agregás : main ... con el bucle de turnos y waitkey, y lo lanzás con /run.

Los pasos 1 a 8 los corrí en una simulación del mecanismo del REPL. El 9 y el 10 no se pueden probar así.
